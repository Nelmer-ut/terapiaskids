# TerapiasKids Store (TypeScript + React + Vite)

Este proyecto es un e-commerce y landing page corporativa desarrollada en **React con TypeScript** y **Vite**, basada en la arquitectura del repositorio de referencia `marlaurita/ecom` del diplomado.

## Características
* **Estructura TypeScript:** Definición de interfaces (`Product`) y componentes tipados con JSX/TSX.
* **Componentes Modulares:** `ProductCard` y `Header` organizados en carpetas independientes con sus propios estilos CSS.
* **Catálogo TerapiasKids:** Datos de programas infantiles, de adolescentes y mujeres emprendedoras extraídos de la psicóloga Elizabeth Rivero.
* **Manejo de Estado (`useState`):** Búsqueda en tiempo real, filtros por categoría de público objetivo y carrito de matrícula interactivo con contador de cantidad.

## Instalación y Ejecución Local

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abrir en el navegador la dirección local (por ejemplo `http://localhost:5173`).
